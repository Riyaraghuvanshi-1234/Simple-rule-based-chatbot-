# simple Rule Chatbot
This is a simple rule-based chatbot created using Python. It takes input from the user and gives predefined responses based on the user's message.

## Features

-Greets the user when they type hello

-Responds to how are you

-Says goodbye when the user types bye

-Shows a default message when it doesn't understand the input

-Keeps running until the user types bye

## Technologies Used

-Python

-If-Else statement

-While loop

-Functions

-User Input/Output

-String handling


## How to Run

Run the following command: python chatbot.py
